The idea

Make room for a different kind of day.

VibeFind is an activity-discovery project built around one simple question: what should we do today? Instead of opening a dozen tabs and scrolling through scattered posts, people can start with a city, an activity or an area and explore the options collected in one place.

The first directory focuses on Delhi and Chandigarh Tricity, bringing together researched listings for gaming, sports, adventure, escape-room experiences, creative activities and more.

It is a starting point, not a claim to list every venue. The directory represents selected places collected for this project, and details such as timings, prices and availability should always be checked with the venue before visiting.

How we approach the directory

Useful first.
Honest always.

Listings are structured from the original research so visitors can compare activity types, browse geographical areas and open map directions. Where a price, booking link, venue photograph or other detail has not been collected, the website should not pretend that it has.

Some locations are approximate, and some source links are third-party listings rather than venue-owned websites. Treat the record as a useful starting point and confirm practical details before setting out.

VibeFind is a student project and an evolving directory. Suggestions for additional places help identify what could be researched next.
