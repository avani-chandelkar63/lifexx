# Current browser preview captures

These are genuine Chromium renders of the current VibeFind page source. The seven main pages have desktop previews at 1440 × 900 and mobile previews at 390 × 844. Additional desktop captures show the homepage discovery chapter, the searchable Area Explorer, and the Explore, Delhi and Tricity result directories.

The execution sandbox blocked ordinary local-file and loopback page navigation, so the page HTML, local CSS and local JavaScript were embedded into the Chromium document for the captures. External Google Fonts could not load; the site uses its included system-font fallbacks in these images. Please use Live Server and the screenshot guide for your own final submission screenshots.
